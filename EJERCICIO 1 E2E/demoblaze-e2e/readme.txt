Prueba E2E Compra Demoblaze

	Tecnologías
- Java JDK 11
- Maven 3.8+
- Serenity BDD 3.9.1
- Selenium 4.9.0
- ChromeDriver 116

	Instrucciones para ejecutar

1. Crear el proyecto Maven.
2. Configurar la ruta de ChromeDriver en `PurchaseFlowTest.java.
3. Ejecutar el test con Maven: mvn clean verify
4. Consultar reportes en: target/site/serenity/index.html
 Requisito IMPORTANTE
- Chrome instalado (versión compatible con ChromeDriver).
